# PART 3 - ANIMATION AND MOTION DESIGN BIBLE
# Version 4.0 - Approved Motion Behavior

MOTION PHILOSOPHY
Motion must communicate clarity, not decoration.
Every animation should support readability and narrative flow.

APPROVED GLOBAL MOTION PROFILE
- Smooth scrolling behavior
- Section reveal on scroll
- Subtle nav state transitions
- Controlled hover motion on interactive cards/buttons/icons

DISABLED OR REMOVED EFFECTS (KEEP REMOVED)
- No traveling glow path on infinity loop
- No obvious animated aurora/grid/particle background effects in final visual result
- No heavy visual noise behind content

HERO MOTION
- Rotating hero text phrases cross-fade in sequence
- CTA enters with subtle delay
- Scroll indicator animates gently
- Hero content should not show highlighted block glow behind the name area

INFINITY LOOP MOTION
- Infinity icons should move clockwise
- Movement should remain smooth and continuous
- No separate glow trail path traveling behind icons

TIMELINE MOTION
- Timeline fill progresses with scroll position
- Timeline cards reveal progressively

COUNTER MOTION
- Business impact numbers animate up on first view
- Animation should be smooth and stable
- Avoid visual flutter by using tabular numerals and fixed numeric width

AI DEMO MOTION
- Simulated typed input and generated response
- Thinking indicator shown briefly
- Input formatting compact and readable (no excessive blank lines)

HOVER INTERACTION RULES
- Hover effects should be restrained and premium
- Prefer subtle lift and border emphasis
- Never over-glow or distract from content

REDUCED MOTION
Provide reduced-motion fallback:
- Disable non-essential animation
- Keep content fully readable and accessible

PERFORMANCE RULES
- No expensive perpetual effects that hurt readability
- Keep JS animation blocks modular and isolated
- Avoid animation that causes layout shift
