# PART 3 — ANIMATION & MOTION DESIGN BIBLE
# Version 3.0

========================================================
MISSION
========================================================

The animations should never exist simply because they look attractive.

Every animation must reinforce the story.

Every movement must guide the visitor.

Every transition must feel intentional.

The visitor should feel like they are travelling through the engineering journey of Amol Jadhav.

The experience should resemble a premium product launch rather than a scrolling web page.

The animation language should be inspired by:

• Microsoft Build
• Apple WWDC
• Stripe
• Vercel
• Linear
• Framer
• Raycast
• Azure Portal

Never imitate gaming websites.

Never imitate hacker-themed portfolios.

Never overload the visitor with excessive motion.

Motion should feel elegant, confident and professional.

========================================================
MOTION PRINCIPLES
========================================================

Every animation should have:

Purpose

Hierarchy

Timing

Momentum

Weight

Depth

Consistency

Never animate everything simultaneously.

Guide the user's eyes naturally.

Use animation to create anticipation.

Never surprise the user with abrupt movement.

========================================================
ANIMATION QUALITY RULES
========================================================

Never animate more than necessary.

Avoid flashy effects.

Avoid spinning objects continuously.

Avoid distracting motion.

Every animation should communicate quality.

The visitor should never think:

"This is an AI-generated website."

Instead they should think:

"This feels like a premium product created by an experienced design team."

========================================================
FINAL MOTION REVIEW
========================================================

Before finishing, evaluate every animation.

Ask:

Does this improve storytelling?

Does it guide the eye?

Does it make the experience memorable?

Does it feel smooth?

Would Apple approve this animation?

Would Microsoft ship this interaction?

If the answer is no,

redesign it before returning the final code.
