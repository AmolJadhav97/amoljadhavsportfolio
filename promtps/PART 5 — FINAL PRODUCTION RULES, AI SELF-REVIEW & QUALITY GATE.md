# PART 5 — FINAL PRODUCTION RULES, AI SELF-REVIEW & QUALITY GATE
# Version 3.0

========================================================
MISSION
========================================================

Do not generate the website immediately.

First think.

Then design.

Then critique.

Then redesign.

Only after the design reaches production quality should the final HTML, CSS and JavaScript be generated.

The objective is NOT to produce code quickly.

The objective is to produce the best personal brand website possible.

========================================================
QUALITY TARGET
========================================================

This website should look like it was created by

• A Senior Product Designer
• A Creative Director
• A Principal Frontend Engineer
• A Motion Designer
• A UX Researcher
• A Brand Strategist

—not by an AI.

The visitor should never think

"This looks AI generated."

Instead they should think

"This is probably custom designed."

========================================================
PRE-GENERATION REVIEW
========================================================

Before writing any code ask yourself

Does this website tell a story?

Does every section have a purpose?

Will HR understand this?

Will engineers appreciate this?

Does it immediately establish credibility?

Does it communicate business value?

Does it communicate technical excellence?

Would I remember this website tomorrow?

If any answer is No

Improve the design before generating.
